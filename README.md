# Burbot

## Database migrations

Copy the example environment file and start PostgreSQL:

```bash
cp .env.example .env
docker compose up -d db-business
```

Install the project dependencies, create a revision after changing a model,
and apply all pending revisions:

```bash
python -m pip install -r requirements.txt
python -m alembic revision --autogenerate -m "describe the schema change"
python -m alembic upgrade head
```

Useful inspection and rollback commands:

```bash
python -m alembic current
python -m alembic history
python -m alembic check
python -m alembic downgrade -1
```

Review every autogenerated revision before applying it, especially enum,
column rename, and destructive data changes.
